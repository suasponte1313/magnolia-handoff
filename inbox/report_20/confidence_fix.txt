=== CONFIDENCE FLOOR ROOT CAUSE & FIX ===
Root cause: The previous confidence calculation used an uncalibrated baseline formula:
    m_conf = 0.70 + 0.25 * float(np.clip(mouth_diff, 0.0, 1.0))
When mouth_diff <= 0 (454 frames in c1), it clipped to 0.0, resulting in exactly 0.700 constant floor.

Correction: Replaced uncalibrated baseline with measured speech token detection confidence
derived from Whisper model posterior word probabilities per frame.
